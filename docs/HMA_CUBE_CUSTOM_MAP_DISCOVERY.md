# CUBE Emerald custom map structural decoding (read-only)

Pinned source: [CUBHMA MapModel.cs](https://github.com/kcradi/CUBHMA/blob/3044393183e01af2ae1e907fb37e4a75eda6a8dc/src/HexManiac.Core/Models/Map/MapModel.cs) and [cube_emerald.toml](https://github.com/kcradi/CUBHMA/blob/3044393183e01af2ae1e907fb37e4a75eda6a8dc/src/HexManiac.Core/ViewModels/QuickEditItems/cube_emerald.toml).

The pinned TOML declares 34 outer bank slots, but its nested map array uses the dynamic ?> terminator. CUBE Mobile **does not guess nested map counts**. The new inspectHmaCubeMapEntry function requires an explicitly supplied per-bank map count (1–1024), bank index and map index. It validates the full custom header and layout field order against the pinned metadata structure before following the declared bank pointer, selected map pointer, 28-byte map header and 28-byte CUBE layout. The decoded layout includes the CUBE isFrlg byte and border dimensions; its complete raw blockmap span is checked and can be read with the existing inspectBlockMap viewport codec.

Every pointer is checked for conventional GBA ROM address shape, alignment, bounds and structural overlap with the bank table, selected map pointer array, map header and layout. No bytes are written. The function is compatible with a staged read-only ROM accessor. Tests use a synthetic CUBE-shaped pointer chain and the attributed upstream TOML excerpt; no copyrighted ROM data is included.

**Important limitations:** matching a format string is not authenticating the ROM, and a user-provided nested count is not independently verified. The decoder is restricted to the pinned CUBE Emerald structural layout and conventional in-ROM pointers. It does not discover map counts, verify ROM provenance, interpret high-bit collision values as walkability, decode map scripts or authorize editing. The returned flags explicitly keep all authentication and write permissions false. Genuine ROM save/reopen, emulator and Android hardware acceptance are still required before strict feature-parity credit.
