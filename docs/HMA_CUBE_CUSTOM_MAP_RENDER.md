# Conservative CUBE Emerald map rendering and raw overlays

Pinned source: [CUBHMA MapModel.cs](https://github.com/kcradi/CUBHMA/blob/3044393183e01af2ae1e907fb37e4a75eda6a8dc/src/HexManiac.Core/Models/Map/MapModel.cs) and [CUBE Emerald TOML](https://github.com/kcradi/CUBHMA/blob/3044393183e01af2ae1e907fb37e4a75eda6a8dc/src/HexManiac.Core/ViewModels/QuickEditItems/cube_emerald.toml).

The opt-in custom CUBE map viewer can now render a bounded 10 × 8 window of 16 × 16 pixel RSE metatiles with primary/secondary palettes and raw attributes, using the existing tested RSE compositor after validating the pinned custom CUBE bank/map/header/layout structure. The custom layout's `isFrlg` field must be zero, and both blocksets must use ordinary light palettes and matching primary/secondary flags. Unsupported CUBE lighting and FRLG variants **fail closed**, rather than being shown as trustworthy graphics.

On mobile, the rendered canvas supports touch selection of a metatile, displaying exact blockmap and attribute source offsets and a revalidated jump to hex. The selected grid origin is shared with the raw spatial grid. Optional categorical overlays distinguish raw six-bit blockmap values and raw metatile behavior bytes. Colors are categories, **not passability, collision policy, or terrain legality**. The overlay legend shows value counts. ROM and metadata replacement, map changes, viewport changes and overlay changes invalidate rendered evidence; tap navigation re-renders and compares pixels, raw cells, attributes and map provenance before navigating.

Synthetic fixture tests verify pixel output, format gates, source immutability and mobile/offline integration. **No genuine CUBE ROM plus matching TOML manifest has been independently authenticated.** No actual emulator/Android device acceptance, safe semantic writing, allocation/repointing or save/reopen transaction has been demonstrated. This work is partial, and strict CUBHMA/CUBE parity remains **0/30** pending independent acceptance evidence. No ROMs or proprietary graphics are included.
