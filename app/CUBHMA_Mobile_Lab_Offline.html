Why did I see rainbow static before?

The old viewer interpreted the first 8 KiB of the ROM as uncompressed 4bpp image data and its header as a colour palette. That was arbitrary binary data, not a decoded sprite. This version starts empty, supports bounded LZ77 decoding and makes palette selection explicit. Tile order, dimensions and palette association still require ROM-aware metadata.

IMPORTANT INFORMATION

About Mobile Lab

This independent web application reads your local ROM. It supports safe copies, hex editing, GBA header checks, patch tools and a graphics inspector with LZ77 tile discovery. It does not include upstream CUBHMA's ROM-specific table parser, map/event/script editors, CUBE version migrations or bundled copyrighted ROM/patch material.

Safety: Back up originals. Only edit offsets you understand. No changes are auto-saved; closing the tab can discard edits. An IPS file carries no source validation. No file is transmitted by this app.

Install: When hosted over HTTPS, use your browser's “Add to Home screen”. The single-file offline edition works directly from your Files app.
